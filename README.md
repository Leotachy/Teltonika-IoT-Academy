# Teltonika IoT Academy 2026

This is a collection of mini projects I've done during my time in Teltonika IoT Academy.
Most of these projects are written in C using CMake build system.
#
### ESP Controller
A collection of OpenWRT daemon packages. *my_esp_controller* daemon exposes UBUS methods for sending commands to ESP devices. *tuyad* is a Tuya client that calls UBUS methods.
### mbread
A simple Modbus makeshift client capable of sending commands to a Modbus server.
### OpenVPN Monitoring
A Lua project for simple OpenVPN server monitoring. Comes with a VuCI API.
### LCD Driver
Linux I2C driver for an LCD screen.
### LED Driver
Linux platform driver for a GPIO pin.
### luipgeo
CMake cross compile project for a simple cURL client.
